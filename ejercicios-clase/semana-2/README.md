# Semana 02 — Ejercicios de Clase

Esta carpeta contiene los ejercicios desarrollados durante la Semana 02 del curso **Análisis de Algoritmos**. Los archivos incluidos aplican principios de programación estructurada, buenas prácticas PEP8 y manejo de funciones.

---

## Archivos incluidos

### 1. `refactor_pep8.py`
Script que implementa funciones para:
- Calcular el promedio de una lista de números.
- Clasificar el promedio según rangos establecidos.
- Mostrar los resultados mediante una función principal (`main()`).

El código está refactorizado siguiendo las normas PEP8 y PEP257.

---

### 2. `clasificador_anios.py`
Programa interactivo que:
- Solicita al usuario una lista de años separados por comas.
- Determina cuáles años son bisiestos usando la regla oficial.
- Muestra la cantidad de años bisiestos y la lista correspondiente.

Incluye validación de entrada y funciones documentadas.
