# Curso Análisis de Algoritmos

Repositorio oficial del curso **Análisis de Algoritmos** para la entrega de los cinco laboratorios evaluativos, ejercicios de clase y scripts de benchmarks.

## Propósito de las carpetas

- **laboratorios/**: Aquí se guardará una carpeta por cada uno de los cinco informes de laboratorio evaluativos del semestre.
- **ejercicios-clase/**: Código de las sesiones prácticas no evaluativas (incluye los ejercicios de Python de la Semana 2).
- **benchmarks/**: Scripts compartidos de medición de tiempos y graficación que se usarán en los laboratorios evaluativos.

## Cómo clonar este repositorio

```bash
git clone https://github.com/roberto-echeverri/roberto-echeverri-analisis-de-algoritmos.git
cd roberto-echeverri-analisis-de-algoritmos
```
